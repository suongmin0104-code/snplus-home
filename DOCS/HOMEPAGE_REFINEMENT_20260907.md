# 홈페이지 개선 근거 및 범위

이전 채팅 검색과 SNPLUS_HOME_NEW_CHAT_HANDOVER_2026-08-09.md 전체 확인. 최신 GitHub main과 운영 HTML 응답을 비교하고 기존 기능을 유지했다.

확인된 문제: 시공사례 버튼이 사진 없는 적용분야 안내를 열었고 개별 사례는 사업소개로 연결됐다. 대표 화면과 사례에서 같은 사진이 반복됐고 회사소개에는 가상 사옥·악수 합성 이미지가 있었다. 첫 화면 preload도 실제 대표 이미지와 달랐다.

개선: 공식 블로그의 실제 현장 6건·사진 9장을 원문에 연결했다. 대표 화면·사업분야·사례·문의 흐름을 정리하고 모바일 글자 크기를 개선했다. 등록 지역·공종은 게시글 기준이며 준공일·금액·수량을 추정하지 않았다.

참고 검색: 대진휀스 https://www.daejin.co.kr/ (제품 분류와 회사자료), 삼우씨엠 https://www.samoocm.com/ (사업·프로젝트 중심 구성), 삼우아이엠씨 https://www.samwooimc.com/ (전문공종 중심 메시지). 검색 결과에서 확인 가능한 구성을 참고했으며 타사 이미지나 문구를 전재하지 않았다. 이들 사이트의 시각적 실화면 검수는 수행하지 않았다.

공식 블로그 https://blog.naver.com/sn6221 의 PostList 본문을 직접 읽고 실제 게시글·이미지 출처를 기록했다. sources.json에 파일별 정확한 원문·이미지 URL을 보관한다. 기존 사업분야 교량 대표 이미지는 유지했으며 신규 실제 사례로 주장하지 않는다.

검증: 정적 lint, production build, 실제 assets 및 hash route 매핑 검사. 기존 API·업무앱은 수정하지 않았다. 실기기/브라우저 렌더링 및 실제 견적 메일 수신은 이번 검증에 포함하지 않았다.
